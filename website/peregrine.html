Peregrine Fil-C: Actually Portable Memory Safe Executables

Since version 0.687, Fil-C can build a runtime sandwich using a fork of Cosmopolitan. This combination is called Peregrine Fil-C and gives you a compiler that:

  • Supports all of Fil-C's memory safety and garbage collection features.
  • Produces executables that run on Linux/x86_64, Darwin/aarch64, and Windows/x86_64.

This is still experimental. Simple programs seem to work great. The main limitations are that the libc doesn't support nearly the same API surface as either native Cosmopolitan, or the musl or glibc releases of Fil-C.
