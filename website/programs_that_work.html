Programs That Work

Lots of programs work in Fil-C with zero or minimal changes. This page enumerates some of the programs and libraries that are known to have been ported to Fil-C along with notes about how many changes were required.

This list is incomplete. It doesn't include ports done by folks who haven't reached out. It doesn't include all of the programs that Fil-C devs have ported. It largely reflects what Pizlix, the memory safe Linux userland, builds.

Some of the programs here claim non-zero changes because I did the port before implementing memory safe inline assembly.
